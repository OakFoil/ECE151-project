# ECE151-project

A console-based banking system

To try it

1. clone the repository
2. If you are on windows install any C++ compiler such as [Visual Studio Build Tools for C++](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
3. If you are on Windows compile using the C++ compiler you installed. If you are on linux then you can use g++

    ``` bash
    g++ main.cpp
    ```

4. Run the output file

    ```bash
    ./a.out
    ```
